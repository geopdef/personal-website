数据分析 Skill

AI 分析规范 · 可执行工作流

持续迭代

日常让 AI 写 SQL 时，容易出现业务口径不清、字段编造、结论无法复用的问题。 因此没有把它设计成单一 Prompt，而是将数据分析师的标准工作流封装起来： 需求澄清 → 场景识别 → 加载业务领域规则 → 表查询网站 MCP 校验表字段 → 生成 SQL → 必要时跑数 → 输出口径、SQL 和结论。

Skill 工作流

标准分析工作流封装

用 SKILL.md 管理总规则与执行铁律，按场景加载口径与模板；写 SQL 前强制 MCP 校验表字段，分析类任务需跑数后再输出结论。

vs Prompt

与普通 Prompt 的差异

普通 Prompt 是一次性任务说明；Skill 是可执行分析规范，解决一致性与可复用性，而非单次回答质量。
